# Notes for Claude

See README.md. Rules for every change in this repo:

- Each tool lives in its own folder as a single `index.html`, linked from the home page (`index.html`) and the README Tools table.
- Every change bumps the version of what changed (the tool, or the home page) and adds an entry to `CHANGELOG.md`. A tool's version appears in its header, on its home-page card, and in `CHANGELOG.md`; keep all three in sync.
- Keep the shared look: dark header bar, Barlow font, light/dark color tokens, mobile-first.
- Don't put changelogs in HTML comments.
